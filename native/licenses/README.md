# Node runtime licence

The unchanged upstream LICENSE for the pinned Node.js v22.23.2 runtime is
included here because some Windows installations ship node.exe without an
adjacent LICENSE.txt. The package builder uses this as its last fallback and
copies the full notice into the installer payload.

Source: https://raw.githubusercontent.com/nodejs/node/v22.23.2/LICENSE
