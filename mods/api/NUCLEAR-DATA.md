# Данные атомной цепочки: дополнение для 1.16

Скриптовая песочница сохраняет API 1.11; это дополнение описывает новые встроенные данные, а не новые методы доступа к DOM, сети или хранилищу. Формат `info.json`, операции `add`/`patch`/`remove` и зависимости модов остаются прежними. Для требований к версии игры используйте `gameVersion`.

## Ресурс и рецепты

`uranium-ore` — встроенный ресурс 6. Он доступен в генерации, сценариях `fmt: 2`, добыче и ресурсных патчах вместе с прежними пятью ресурсами. Параметры `richness` и `size` изменяют встроенный ресурс; произвольное добавление новых номеров руды этим не обещается.

Новые рецепты разделения, обогащения и переработки используют категорию `centrifuging`; встроенная `centrifuge` имеет её в `cats`. Вероятностные выходы разделения задаются полем `rout`: список пар `[item, weight]`. У `uranium-processing` веса 7 для U-235 и 993 для U-238. Это один случайный результат партии, а не два гарантированных продукта. Оборотные изотопы и отключённая продуктивность ядерных рецептов относятся к материальному балансу.

## Поля сооружений

| Поле / тип | Значение |
|---|---|
| `type: "reactor"` | реактор с топливным циклом, соседством и аварийной логикой |
| `type: "hpipe"` | тепловая труба |
| `type: "hexch"` | теплообменник: тепло, вода и выход пара |
| `heatC` | теплоёмкость в МДж/°C; встроенные значения: реактор 10, труба и теплообменник 1 |
| `turbine: true` | паровая турбина типа `engine`; преобразование энергии горячего пара |
| `maxOut` | электрическая мощность генератора в кВт; встроенная турбина — 5820 |
| `fluid` | прежние жидкостные камеры с `cap`, `filter` и `conns`; тепло не является жидкостью |

Все патчи проходят проверку схемы и диапазонов. Изменение `heatC` меняет связь энергии и температуры, поэтому проверяйте последствия на копии мира. Произвольный параметр мощности реактора не следует придумывать: встроенная формула использует базовые 40 тепловых МВт и соседство.

## Сигналы реактора

| ID | Единица / смысл |
|---|---|
| `signal-temperature` | округлённые °C |
| `signal-heat` | тепловые кВт |
| `signal-neighbours` | число действующих соседей |
| `signal-fuel-time` | оставшиеся игровые секунды активной ячейки, округление вверх |
| `signal-overheat` | 1 при температуре от 1000 °C |
| `nuclear-fuel-cell` | ячейки во входном запасе; уже горящая ячейка сюда не входит |
| `used-nuclear-fuel-cell` | отходы на выходе |

Для парового резервуара `signal-energy` показывает долю сетевой энергии его камеры в МДж. Общая жидкостная сеть не создаёт отдельный полный запас для каждого резервуара.

Состояние ядерной цепочки сохраняется в формате партии 18. Версии игры, данных и набора модов проверяются при сетевом подключении; экспорт нового сценария для 1.15 не обходите ручной заменой `fmt`.
