# Подтверждение RTX 4060 на ноутбуке

Пользователь прислал снимок действующей игры и сообщил «теперь есть». На снимке F3 показывает `рендер webgl` и `ANGLE (NVIDIA, NVIDIA GeForce RTX 4060 Laptop GPU …)`, FPS 60. Это подтверждает использование дискретной видеокарты действующим рендерером на момент снимка после настройки приложения в Windows.

[Исходный снимок пользователя](native-gpu-v116-user-rtx4060.png) сохранён без изменения пикселей. Это наблюдение одной работающей сцены, а не длительный FPS-бенчмарк или проверка всех уровней нагрузки. Ранние отчёты `native-gpu-v116-before-hint.json` и `native-gpu-v116-after-hint.json`, где использовалась Intel UHD, остаются историческими результатами предыдущих запусков.
