# Ручная приёмка 1.17: чистая Windows и новые игроки

Проверяемый кандидат: 1.17.0-dev.1. Это протокол получения свидетельств, а не результат теста.

## Установка на чистой Windows

Использовать отдельный ПК или одноразовую VM Windows x64 с Chrome/Edge. Node и ЗАВОД-7 заранее не устанавливать. Не использовать основной игровой профиль владельца как «чистую систему».

1. Распаковать игровой архив целиком. Записать имя архива, SHA-256, версию Windows и браузера. Сделать снимок VM до установки.
2. Запустить `native/Zavod7-Server-Setup.exe`. Отдельная установка Node, права администратора, терминал и настройка роутера не должны потребоваться.
3. Проверить появление приложения/значка трея, регистрацию `zavod7:` и автозапуск только для текущего пользователя. Записать фактические пути, не содержимое личного хранилища/ключей.
4. В игре открыть совместную игру, создать мир, положить несколько предметов в инвентарь. Одной кнопкой включить сервер; записать время до готовности. Закрыть игровую вкладку: процесс сервера должен остаться, второй игрок должен продолжить игру.
5. Войти владельцем обратно. Проверить прежнего инженера, позицию, инвентарь и прогресс мира; сервер выключить и включить из меню. Код и исходный срок ещё действительного приглашения должны сохраниться.
6. Перезапустить Windows. Приложение должно штатно восстановить контроллер без второго экземпляра сервера. Повторить включение/остановку. Проверить мир и резервные копии.
7. Повторно запустить тот же установщик; повреждённый или неполный пакет не должен уничтожить действующую поставку/сохранение. Проверку отказа проводить только после снимка VM и копии мира.

Не присылать `controller.json`, токены, гостевые ссылки с фрагментом и приватные ключи. Для отчёта достаточно обезличенных шагов, ошибок/скриншотов и времени.

## Понятность запуска — 5 новых пользователей

Каждый человек раньше не пользовался этой функцией. После установки дать только цель: «включить свой ПК как сервер и подключить второго игрока по приглашению». Не объяснять кнопки устно и не вести человека по шагам.
