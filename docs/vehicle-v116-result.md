# Автомобиль 1.16 — результат реализации

Эта рабочая копия добавляет автомобиль 2×3 и его оборудование в `game-v1.16`. Версию выпуска не менял. Для сетки машины разрешены только `solar`, `reactor`, `battery` и `nreactor`: источники/накопители питают отдельные лазерные турели автомобиля. Щиты, личные лазеры, экзоскелеты, дроны, робопорты и подкладка в эту сетку не входят.

| Требование | Реализация | Исполняемая проверка |
|---|---|---|
| Корпус 2×3, 1000 HP, скорость до 20, двигатель 150 кВт только при движении, отдельный топливный слот, багажник 40; рецепт и технология | `src/data/entities.ts`, `src/data/items.ts`, `src/data/recipes.ts`, `src/data/techs.ts`, `src/sim/game.ts`, `src/sim/perf.ts` | `tests/v116vehicle.test.ts`: данные рецепта/технологии, разгон, реальный расход и остановка без расхода |

## TDD и проверка

RED был зафиксирован до реализации поддержки реактора автомобиля: целевой тест завершался с exit 1 на whitelist/установке `nreactor`, загрузке стержней, цикле и подаче мощности; отдельный тест также падал, потому что обычная и изотопная канистры наносили одинаковый урон. После реализации целевые проверки стали зелёными.

- `& .\node_modules\.bin\tsx.cmd tests/v116vehicle.test.ts` — exit 0.

- `npm run build:dev` — exit 0; offline dev-сборка `dist/index.html`.

Сверка файлов с `D:/Project/webfactory/parallel-base-v1.16` показывает следующие отличия в коде/проверках; отчёт добавлен отдельно:

`package.json`, `src/data/entities.ts`, `src/data/items.ts`, `src/data/recipes.ts`, `src/data/techs.ts`, `src/render/art.ts`, `src/render/renderer.ts`, `src/sim/combat.ts`, `src/sim/game.ts`, `src/sim/heat.ts`, `src/sim/nethash.ts`, `src/sim/perf.ts`, `src/sim/scenario.ts`, `src/sim/snapshot.ts`, `src/ui/ui.ts`, `tests/v116d.test.ts`, `tests/v116vehicle.test.ts`.

## Что остаётся проверить при интеграции

Этот целевой цикл не запускал полные `npm test`, E2E, mega-тест без quick, кроссбраузерный набор, двух десятичасовых игровых сценариев, hardware benchmark или ручной визуальный плейтест. Нужны финальные проверки из общего плана 1.16 на интегрированной сборке. Dev-сборка пригодна для независимого UI review, но один её успешный запуск не подтверждает GPU/performance критерии или объявление финального релиза.
