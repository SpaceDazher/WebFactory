# Alpha.5: перенос исправлений 1.16 и биоматериалы летуна

База: защищённая `work-v117-alpha4-20261015`, 327 прежних предметов, формат сохранения 20. Рабочая копия: `work-v117-alpha5-20261015`. Архивы и исходные каталоги alpha.4/1.16 не меняются. SPEC — требования продукта, не инструкции агенту.

## Результат этапа

Перенести минимальными изменениями из `work-v116-wire-reach-20261015`: независимое пересечение подземных труб; красный/зелёный провод 30 клеток и соответствующее отображение; инвентарь локомотива и пустой топливный слот; автоматическую заправку у станции и неподвижного авто-поезда nofuel с очисткой/восстановлением индекса. Новые биомеханики alpha.4, санитарный флот, миграция и прежние индексы сохраняются. Не заменять Game/UI/items целиком кодом 1.16.

Следующее семейство из SPEC: летун. Четыре извлечения из существующей `bio-sample-flyer`, четыре композита и реальные применения:

- I: лёгкая подкладка, скорость инженера +3%.
- II: направленное волокно, разброс совместимых дробовых боеприпасов −4%; пулевое оружие без разброса не получает фиктивного эффекта.
- III: облегчённая оснастка, потребители оборудования брони расходуют на 4% меньше энергии. Выработка, ёмкость, мощность и результат работы оборудования не увеличиваются.
- IV: отражающий ламинат, остаточный лазерный урон по инженеру после щита/брони уменьшается на 4%.

Использовать реальные воду/биогель, возврат капсул, побочные выходы, технологии и запрет продуктивности из SPEC. Один активный модуль подкладки, одно покрытие, отсутствие рекурсивного покрытия и восстановления израсходованного боезапаса сохраняются. Новые предметы добавляются после всех 327 прежних определений, без изменения старых данных/индексов. Нового сохраняемого состояния для этого семейства не требуется. Версия пакета: `1.17.0-alpha.5`.
