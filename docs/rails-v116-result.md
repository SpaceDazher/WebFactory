# Железнодорожный поток v1.16

Этот отчёт покрывает только рельсы и поезда; он не означает, что весь выпуск 1.16 завершён.

## Реализовано

- Перетаскивание строит 1–4 независимо проложенных пути. Шаг по умолчанию — 4 клетки; для чётного числа путей шаг изменяется кратно 4, для нечётного — 2. Клавиши `1`–`4` выбирают число путей, `+`/`−` меняют шаг, `Shift` оставляет призраками всю трассу. Превью показывает соединительные узлы, занятые сегменты, нехватку рельсов и удалённые участки как призраки. Максимальная прямая трасса ограничена 500 сегментами.
- Каждая линия проходит A* отдельно по допустимым рельсовым формам. Повороты используют штатные внутренние и внешние кривые с их минимальным радиусом; после расчёта линии проверяются на пересечение и минимальный зазор. Узлы краёв при необходимости разводятся дальше, вместо смещения готовой копии трассы.
- `Escape`, правая кнопка и потеря фокуса отменяют текущий drag без команды на изменение мира. Симуляция перед укладкой повторно проверяет весь путь; при новом препятствии отменяется вся операция. Недостающие или удалённые от игрока сегменты становятся призрачными. Размещение одной трассы записывается одной группой undo; replay находит именно её рельсы и призраков.
- Превью не генерирует неизведанные чанки: такие участки показываются призраками, а их рельеф и препятствия проверяются симуляцией при подтверждении. На ранее медленном маршруте через новые чанки p95 планирования снизился с **208.07 мс до 3.73 мс**. Полный расчёт с obstacle/range классификацией на уже известных чанках занимает p95 **14.37 мс**.
- Челнок из 2 передних локомотивов, 8 грузовых вагонов и 2 обратных локомотивов проходит терминалы туда и обратно, сохраняя тяговые группы по концам. Проверены парные сигналы, ручное управление выбранным локомотивом, груз, сохранение в пути и одинаковый хеш после продолжения.
- Проверка команды `railPath` ограничивает пакет 2000 сегментами, принимает только допустимые направления рельсов и безопасный диапазон координат упакованной сетки, а также отклоняет разреженные команды, требующие более 256 новых чанков, до генерации мира. Хеш сохранения строится с каноническим порядком ключей, чтобы вставка сигналов в разном порядке не меняла сетевую контрольную сумму.

Превью четырёх трасс по 500 сегментов с ленивой проверкой чанков: p95 **3.73 мс**; полный preview на известных чанках: **14.37 мс** (лимит 50 мс для обоих измерений).
