# RTX 4060 — длительный замер итогового кандидата

Родитель запустил встроенный `runBench` в отдельном установленном Chrome **137.0.7151.69** через `C:/Program Files/Google/Chrome/Application/chrome.exe`. В обеих сборках фактический активный WebGL-контекст сообщил **ANGLE / NVIDIA GeForce RTX 4060 Laptop GPU / Direct3D11**. Принудительные GPU-флаги и программный рендер не использовались; пользовательский профиль Chrome не изменялся.

Одинаковые условия: 1600×900 при DPR 1, `render=webgl`, `gfx=low`, стандартный прогрев 6 секунд и три масштаба по 10 секунд, без `benchfast`. Встроенный замер временно снимает ограничение FPS только в своей вкладке. Тяжёлые проверки других агентов были приостановлены. Перед объединением сохранён прежний minified `index.html`; после объединения выполнен тот же `npm.cmd run build` с минификацией. В обоих случаях версия остаётся RC.7.

| Сцена | До объединения: худший FPS / p95 кадра / UPS | После объединения: худший FPS / p95 кадра / UPS |
|---|---|---|
| L4 | 179,54 / 5,8 мс / 59,90 | 179,49 / 5,7 мс / 59,92 |
| L5 | 145,23 / 11,2 мс / 59,95 | 145,28 / 11,2 мс / 59,84 |

Оба запуска завершились exit 0, встроенный `ok60` истинен для обоих уровней, ошибок страницы нет. Значения — худший результат среди трёх масштабов; это одна пара последовательных запусков, а не статистическое доказательство ускорения. Замер относится к выбранному профилю графики и этим сценам; он не доказывает выполнение отдельного бюджета перестройки тепловой сети или отсутствие рывка при аварии.
