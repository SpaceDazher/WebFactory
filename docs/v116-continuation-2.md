# Продолжение 2 — водоснабжение обычного бота

## Результат

Исправлен воспроизведённый отказ поиска трубы `water-p` от (-172,-605). Адаптивный вариант проходит точную сохранённую фикстуру, физическую проверку воды/пара, проверки лимита поиска и предыдущих коротких трасс. **Тихий полный npm test завершился exit 0**, включая botdef и проверки после него. Версия остаётся **1.16.0-rc.7**, не финальная 1.16.0.

Физика и UI не менялись: все файлы src/ побайтно совпадают с первоначальным архивом. Все 56 исходных файлов tests/saves также совпадают с архивом. Нового игрового архива для изменений только в инструментах не требуется.

**Полный npm run bot до ракеты не засчитан.** Адаптивный запуск прошёл прежнюю точку отказа и создал контрольное сохранение на tick 2 376 000 (11 игровых часов), но rockets=0. Между исполнительными сеансами процесс и его handle исчезли; итоговый отчёт и exit-файл не появились. Точный сигнал завершения не установлен. Это прерванный, а не успешный или завершённый неуспешный прогон. Последнее реальное сохранение: integration-logs/continuation-2/bot-adaptive-last-checkpoint.z7save. Оно содержит состояние игры, но не продолжение генератора и памяти планировщика Bot; нельзя выдавать открытие этого сохранения за продолжение той же CLI-проверки.

## Диагностика и реализация

На коде продолжения 1 полный seed-1 бот снова упёрся в водоснабжение на tick 995369. Захвачены реальные Game/Plan, все 272 прежние цели и координаты портов. Вход свободен: pipeOk=true, occ=-1, keep=false. Повтор точного поиска подтвердил остановку по лимиту: 300000 извлечений, 319741 созданный узел, route=null. Это не отказ установки насоса или занятая стартовая клетка.

Фикстура `tests/fixtures/bot-water-failure.json.gz` — сжатая копия этого захвата, без изменения масштаба, целей, портов, нагрузки или расположения построек. Новый тест сначала наблюдал RED.

Первый кандидат сразу использовал более точную допустимую нижнюю оценку: минимальная цена перехода подземной пары равна (2.6+0.3×10)/12 = 5.6/12 за клетку. Он нашёл воду, но изменил ранние трассы: полный npm test упал на нехватке small-electric-pole в botdef. Этот кандидат отклонён; его обычный бот остановлен и не считается доказательством приёмки.

Принятый кандидат сохраняет прежний порядок с коэффициентом 0.4 для обычных поисков. На границе первой трети существующего бюджета он повышает оценку до 5.6/12 и пересобирает приоритеты **оставшейся очереди**. Поиск не перезапускается, счётчик не сбрасывается, общий лимит остаётся 300000. Условия геометрии, воды, чужих сетей и препятствий не ослаблены. Добавлена необязательная статистика причины завершения поиска.

Точная фикстура: найдено 230 элементов трассы за 233023 извлечения, 258723 созданных узла. Все элементы проходят настоящую canPlace/build; после 180 настоящих Game.step все три бойлера физически соединены с существующим береговым насосом и производят пар. Фикстура подготавливает снос декора и выдаёт бойлерам только уголь, не воду/пар/электрическую выработку. Это проверка геометрии и симуляции, не полное прохождение экономики игроком. Три обычные короткие трассы побайтно совпадают с результатами продолжения 1; эталоны получены прежним кодом, а не кандидатом.

Изменения этого этапа: tools/bot/map.ts и package.json; новый tests/bot-water-route.test.ts и две новые фикстуры. В npm test добавлен новый регресс без удаления прежних команд. Исправления восстановления бота из продолжения 1 сохранены.

## Открытые условия и следующий этап

1. Полный обычный бот до ракеты требует нового непрерываемого запуска `npm run bot` в окружении с достаточным временем жизни процесса. Последний прерванный мир показывает прогресс до 11 часов, но не запуск ракеты. Не сокращать сценарий, не телепортировать бота и не менять таймауты/материалы ради GREEN.
2. Строгие split/merge тепловые бюджеты, одиночный рывок каскадной аварии и относительный REF против 1.15 остаются открытыми. Эти измерения на данном этапе не повторялись.
3. Полный mega с прежними golden, полный E2E Chromium/Firefox/WebKit, настоящая потеря фокуса рельсовой кисти и ручная приёмка остаются открытыми. Их проверки не заменяются зелёным npm test.
4. Основной GPU-тест прошёл в программном окружении на предыдущем этапе; старый межмашинный/интермиттирующий результат и RTX 4060 здесь не перепроверялись.

Следующая ограниченная задача разработки: локальное обновление теплового графа при split/merge с неизменённым строгим стендом, сохранением энергетического учёта и исходных порогов. Отдельно закрыть непрерываемый полный бот. Финальная 1.16.0 не выпускается, механики 1.17 не добавлялись.
