# Атомная цепочка через UI обычной партии

База: настоящее сохранение bot-прохождения до ракеты, 8 игровых часов. Управление — мышь, клавиатура и видимые кнопки; Worker читается только для доказательств. Не выдавать вещи/технологии, не менять координаты/физику/счётчики. Это агентский плейтест.

Проверить импорт сохранения и сохранённый прогресс; поиск урана на карте; исследование атомной ветки до ракеты; кислотную добычу; реальный цикл центрифуги; изготовление стержня; нагрев и электрическую выработку; получение отхода и его переработку. Сохранять видимый результат и авторитетные счётчики.

Контролы: меню загрузки, карта и контур месторождения, очередь исследований, крафт и запасы, окна рецептов/портов, пуск/остановка реактора, оповещения/радиация, сохранение и повторная загрузка. Проверить полный цикл обратимых переключателей. Визуально проверить HUD, порты, статистику, исходную и плотную сцену, отсутствие обрезанных кнопок.

Отдельные отрицательные пути: отсутствие кислоты; отмена незавершённого крафта без потери резерва. В конце подтвердить cheatsUsed=false, survival и отсутствие запущенной ракеты. После основного маршрута — короткое исследование UI мышью/клавиатурой.

Интерактивный Node runtime дважды завершился до выполнения кода. Фактически использована альтернатива: системный Node CLI с Playwright и изолированным временным контекстом Chrome137. Постоянный профиль пользователя не используется. Queries Worker читают состояние; движение, добыча деревьев, крафт, перенос предметов, выбор рецепта и строительство выполняются настоящими событиями мыши и клавиатуры.
