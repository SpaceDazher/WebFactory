# Браузерная среда проверки выпуска 1.16

Наблюдения родителя от 12.10.2026. Это проверка среды, а не изменение графических настроек компьютера.

- В ограниченном exec Chrome 137 с временным профилем использовал Intel UHD. Четыре исходных CPU p95-проверки E2E14 не проходили в нескольких сохранённых запусках. Эти отказы сохранены и не объявляются зелёными.
- Чтение HKCU `DirectX/UserGpuPreferences` вне ограниченного exec обнаружило уже существующую настройку `GpuPreference=2;` для `C:\Program Files\Google\Chrome\Application\chrome.exe`; внутри ограниченной среды эта запись не была видна. Запись не изменялась.
- Запуск того же Chrome вне ограничений через временный профиль подтвердил фактический `window.__zavod.R.gpuNote()`: NVIDIA GeForce RTX 4060 Laptop GPU, аппаратный ANGLE. Доказательство: `integration-logs/release-1.16-20261012/gpu-unsandboxed.log`, exit 0. Первоначальная ошибка вызова helper `appUrl` была исправлена передачей URL тестового модуля; рабочий повтор записан в этот лог.
- Неизменённый E2E14 вне ограничений, `PW_BROWSER=chromium`, `PW_EXECUTABLE_PATH` = системный Chrome, `PW_HEADLESS=0`, завершился exit 0. Auto при zoom 1 / 0.5: p95 14.10 / 10.70 мс. Явный WebGL: 10.60 / 10.40 мс. Все исходные пределы 16.7 мс сохранены; UPS 59.8–60. Лог: `e2e14-native-unsandboxed.log`.
- Старые установленные Playwright Firefox не запускались из-за side-by-side конфигурации Windows. Свежий официальный Firefox 153.0 установлен инструментом существующего Playwright в отдельный `D:\Project\webfactory\browser-cache-release-v116`, не меняя версии зависимостей проекта или прежний cache. Установка завершилась exit 0.
- Свежий Firefox внутри ограниченного exec запускал процесс, но создание страницы падало с `_page`. Временное отключение content sandbox подтвердило зависимость от среды; это не используется как финальная среда проверки. Вне ограничений свежий Firefox со стандартным content sandbox создал страницу успешно, exit 0 (`firefox-unsandboxed-default.log`).

Для итоговых браузерных проверок используется запуск временных браузерных процессов вне ограниченного exec. Firefox сохраняет стандартный content sandbox. Системные GPU-настройки и постоянные профили пользователя не изменялись. Аппаратный результат относится к указанному ноутбуку и фактическому RTX-контексту; он не гарантирует такую же скорость на Intel или SwiftShader.

## Отказы, найденные после настройки среды

Firefox5–9 прошли, но E2E10 воспроизводимо падал при навигации с начальной страницы на `?render=webgl`: два запуска с окном и один без окна дали `Page crashed`. Старт на новой странице с тем же URL работает (диагностика исполнителя, отдельно от итоговой приёмки). Также первая проверка E2E10 ожидает принудительный Chromium SwiftShader, хотя его аргументы неприменимы к Firefox. Это требует раздельной диагностики тестового ожидания и падения процесса. [Upstream Firefox issue42565](https://github.com/microsoft/playwright/issues/42565) описывает похожую регрессию Firefox153 при перезагрузке во время компиляции Worker; совпадение причины для этой игры пока является гипотезой.

Windows WebKit26.5 прошёл E2E5, но E2E6 выявил отсутствие звука и отказ офлайн-перезагрузки PWA. Родительская проверка отдельной `about:blank` подтвердила: `AudioContext`, `webkitAudioContext`, `OfflineAudioContext`, `RTCPeerConnection` отсутствуют; `WebGL2RenderingContext` есть. Лог `webkit-native-capabilities.log`, exit0. Такая сборка не предоставляет API для проверки реального звука и WebRTC. На компьютере уже существует Ubuntu-24.04 в WSL; проверка его среды начата. Эти проверки не удаляются и не объявляются пройденными.

[Upstream WebKit issue42273](https://github.com/microsoft/playwright/issues/42273) касается другого, похожего отказа автоматизированной перезагрузки с service worker; сообщение сопровождается успешной проверкой более новой версии. Оно не доказывает причину нашего отказа. Нужна собственная диагностика на полноценной сборке WebKit.

Итоговую готовность выпуска этот документ не подтверждает: полный набор браузерных сценариев и другие приёмочные команды ещё выполняются.

## Уточнения 13 октября 2026

Для актуальной проверки Firefox используется отдельный Playwright 1.64.0 и Firefox 157.0 (build1555), со стандартным content sandbox. E12 и E13 завершились exit0. Зависимости и lockfile игры не заменялись этим вспомогательным SDK. Ожидание готовности Worker перед навигацией в E10 сохраняет саму проверку смены рендера.

Linux WebKit27.2 в Ubuntu-24.04/WSL предоставляет WebAudio и WebRTC. E5–8 прошли; E6 проверил настоящий звук, IndexedDB и офлайн-перезагрузку PWA. Неизменённый E8 завершился exit0 за268,4с: все3429 проверки подсказок, RU/EN и масштаб200% прошли. Предыдущие внешние таймауты240/300с не означали остановки движка: диагностический журнал показывал продолжающиеся проверки. Финальный запуск выполнен без внешнего ограничения времени; утверждения не удалялись.

В этой конкретной сборке WebKit скриптовые моды из файлового origin не запустились: верхний Blob Worker работал, вложенный Worker вызывал onerror без текста. Такой же зонд на временном http://127.0.0.1 работал. E26 теперь проверяет размещённую игру через локальный сервер, который обслуживает только dist; все проверки модов, безопасности, хранения, GUI и карты сохранены. E26 на этом origin прошёл exit0 за29с (`e2e26-map-coordinate-http-green.log`). Это доказательство HTTP-режима; работу вложенных Worker в офлайн file-origin этой сборки оно не подтверждает. Отдельный Safari/macOS не запускался.

В реальном игровом UI1600×900 родитель воспроизвёл горизонтальную обрезку большой карты: полотно1002px при доступных734px. Исправление ограничивает полотно шириной панели и совмещает контуры с областью рисования без рамки. Дополнительный тест обнаружил смещение координат2,18 клетки; исправление mapAt/перетаскивания уменьшило измеренную погрешность до0,00 клетки. E26 сохраняет проверки масштаба, клика и точной постановки метки.

Обычная атомная партия импортирована через штатный file chooser из настоящего bot-сохранения до ракеты. Переработка урана исследована за реальные научные пакеты; ядерная энергетика начата, оплаченный прогресс прежнего исследования сохранён. Ledger в `integration-logs/release-1.16-20261012/atomic-normal-ui-ledger.ndjson` фиксирует survival/mode0, cheats=false и rockets=0. Это пока частичный агентский плейтест; добыча/топливо/выработка/переработка в нём ещё не приняты.
