# Continuation-12: приёмка p95 тепла 8 мс пройдена

12 октября 2026. Код версии **1.16.0-rc.7**, этап continuation-12. Пользователь явно изменил порог p95 тепла с 6 на **8 мс**; p95 полного Game.step остался **16,67 мс**. Это приёмка этапа оптимизации на данном стенде, а не объявление финального релиза 1.16 или гарантии FPS на каждом ПК.

## Изменение

Тепловые проходы используют сохранённые ссылки на строки edgeSlots/pipeSlots в исходном порядке storage.keys. Общий список этих ссылок создаётся один раз, при первом обращении физики в том же stepHeat. Промежуточные сети, которые reactorCause пересобирает для диагностики после взрывов, не собирают эти списки. Нет переноса работы за пределы Game.step; порядок передачи, ограничения потоков, Number-арифметика и накопление потерь прежние.

В этом этапе из 113 файлов src изменён только src/sim/heat.ts. SHA256: **eddadbca045b8f022756b582dafc5b421c479b52138a80dc23be34ac0ba662ed**. Package.json/package-lock прежние. В tests/heat-local-rebuild.test.ts дополнены проверки, старые случаи сохранены. Активный код совпадает со снимком source-candidate-heat8-cycle2. Родитель проверил все 113 файлов, неизменность входной C3-базы и физического стенда. Относительно принятого continuation-10 сохраняются также прежние C3-оптимизации жидкостей из src/sim/networks.ts; их история и проверки включены в архив.

Работа выполнена одним фактически запущенным GPT-6-Luna, reasoning max, fork none: два реализационных цикла, затем независимая проверка родителем. В конце субагент достиг лимита использования после передачи результатов; сохранённые изменения и исполнимые проверки были независимо проверены родителем. Дополнительный агент не создавался. План: docs/heat8-20261012.plan.md.
