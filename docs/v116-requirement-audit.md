# Независимый аудит требований 1.16

Обновление доказательств 09.10.2026: актуальные результаты объединённого кандидата приведены в [журнале проверок](v116-checks-20261009.md), который заменяет устаревшие состояния ниже. Сборка, типы, переводы, баланс, bench/test:perf и три 10-игровых-часовых атомных прогона проходят. Сохранность архивных saves проверена отдельно. Длительный одинаковый замер до/после в установленном Chrome 137 подтвердил RTX 4060 и более 60 FPS/около 60 UPS на L4/L5 при указанном профиле. Реальный рельсовый MP проходит в трёх движках. Полный npm test остаётся красным на botdef, полный mega — на исходном v1.8-late; отмена рельсового drag при потере фокуса не доказана автоматическим драйвером. Финальный тепловой стенд после третьего цикла не проходит лимиты перестройки графа; одиночный тик массовой аварии сократился примерно с 77 секунд до 0,466 секунды, но рывок остаётся. Восстановление WebGL независимо проверено диагностическим запуском с полным сохранением партии; основная команда теста красная на немедленном чтении F3. Циклы бота, REF, тепловой сети и GPU закончены без четвёртой реализации; новый общий браузерный прогон фиксирует отдельные фронтиры отказа. Полный релиз не принят, версия остаётся RC.7.

Дата: 09.10.2026. Объём сверки: полный `docs/zavod7-v1.16-spec.md`, включая §§1–16 и дополнения 15.1–15.3, и `docs/v1.16-completion.plan.md`. Проверяется ветка `release-v1.16`; требования 1.17 и позднее исключены. Этот документ — аудит покрытия, не объявление релиза готовым.

Статусы относятся к имеющемуся доказательству, а не только к наличию кода. «Частично» означает, что focused test или код подтверждает узкий сценарий, но не продуктовый критерий. «Не закрыто» означает отсутствующее/неуспешное исполнение либо известное несоответствие.

## Вывод независимого аудита

В исходниках есть реализация большинства крупных веток 1.16 и targeted evidence; direct save evidence подтверждает ручное завершение атомного сценария, nuclear acceptance — три десятичасовых профиля и bounded physical normalization, а четыре поставляемых старых mod ZIP проверены реальным парсером/registry/save/load. Release acceptance пока не выполнен: полный npm test и E2E-runner не green, paired REF cycle 3 pooled p95 regression составляет 11.73% (все три round ratio выше 1.10), а timed full-count heat stages пока не проверены. Новая fixture доказала full-count pump/steam/load activity за 300 шагов, не p95. Остаются финальный old-save regression, GPU/archive/checklist и полный release runner.

В §15.3 source-уровневые прежние gaps перепроверены: group-rate history и per-player alert acknowledgements сохраняются в save/hash, shared-fluid capacity распределяется по узлам без двойного счёта, одинаковые alert causes coalesce по kind/target, а planner preview проверяет геометрию и stale obstacles. Diagnostic timer p95 0.68 ms/max 0.70 ms на 3,002 entities/12 requests относится только к diagnostic slices. Остаются browser/MP acceptance для group/chart, alert acknowledgement UI и planner multi-client journey; эти локальные проверки не заменяют full-tick/heat stress benchmark.

Итоговая браузерная матрица на объединённом minified dist завершена с exit 1 во всех трёх движках: Firefox 153 — E2E7 (сохранение после перезагрузки), WebKit 26.5 — E2E6 (WebAudio и внутренняя ошибка reload), Chromium 151 — E2E20 (меню совместной игры и тайм-аут поля). Chromium E2E5–19 прошли; после каждой указанной границы дальнейшие сценарии не выполнялись. Все exit-файлы и концы логов независимо проверены родителем. Финальная версия и архивы не выпускаются.
