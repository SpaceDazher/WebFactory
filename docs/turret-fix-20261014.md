# Исправление турелей — 14 октября 2026

Версия остаётся **1.16.0-rc.7**. Это игровой кандидат с исправлением двух ошибок; общая приёмка финального 1.16 остаётся приостановленной.

Обычные наземные турели теперь выбирают ближайшего подходящего подвижного врага, гнездо или червя. При равном расстоянии сохраняется приоритет юнита; структуры с равным расстоянием выбираются по ID. Сохраняются ограничения земли/воздуха, дальности и мёртвой зоны, расход патронов, жидкости и энергии. Текущая цель проверяется на существование и дальность перед стрельбой. Пулемёт и лазер наносят структурам урон через обычный механизм повреждения построек; ракеты по структурам летят к фиксированной точке без путаницы с ID юнитов. Огнемёт, миномёт, Tesla и рельсотрон также могут начать атаку по структуре.

Причина: прежняя обычная ветка искала только `Unit`, тогда как гнёзда и черви представлены `Entity`. Кэш использует существующее поле `tgtU`: юниты >= 0, отсутствие цели -1, структура -(id+2). Новых полей или версии сохранений не добавлено. Проверка автомобильных сохранений принимает безопасные целые отрицательные значения и отклоняет дробные и выходящие за безопасный диапазон.

Радиус включён по умолчанию при наведении, добавлен при установке турели, включая поворот, мёртвую зону и бонус дальности артиллерии. Режимы выключено/наведение/все сохранены; на большой карте кольца подавляются. Центры колец автомобильных турелей соответствуют реальным точкам стрельбы.

Изменены четыре из 113 исходников: `src/sim/combat.ts`, `src/sim/compat.ts`, `src/render/renderer.ts`, `src/main.ts`. Родитель проверил SHA-256 остальных **109 исходников**: изменений нет. Все ранее выполненные рисунки и исправления мультиплеера сохранены. Расширены три существующих теста; зависимости, версия и формат сохранений не изменены.
