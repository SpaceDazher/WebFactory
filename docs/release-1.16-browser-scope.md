## Release 1.16.0 target

The required browser set is Windows Google Chrome and Microsoft Edge. The candidate bundle used for the Edge runs is `dist/index.html` SHA-256 `B04FA259F847E94EAED8A1FB2C89DB9F0B48CFF9AEA66168F529ADCB15C5243A`. Edge 155.0.4283.45 was confirmed through Playwright's `browser.version()` using the installed `msedge.exe`. Edge E5–33 functional checks pass, including E14 on the designated RTX 4060 reference path. E9 exits 0 on the test's explicit SwiftShader software-rendering path: WebGL and Canvas2D match at both zooms (0.00% differing 4×4 blocks), both remain within the legacy-render similarity gate, and WebGL is faster than legacy for the middle layer. E15 exits 0 in native headed Edge and reports ANGLE Intel UHD Graphics (hardware); the 1,906-entity benchmark reports 170.3 FPS and p95 5.8 ms with `ok60=true`. Exact logs for the E9, Intel E14, E15, and RTX E14 runs are `integration-logs/release-1.16-20261012/e2e-edge-155-9-quiet.log`, `e2e-edge-155-14-native.log`, `e2e-edge-155-15-native.log`, and `e2e-edge-155-14-rtx.log`. `edge-155-final-matrix-artifacts-v2.json` records SHA-256 and byte length for the archived logs, screenshots, and test sources. The matching evidence bundle is `edge-155-final-evidence-20261013.zip`; its SHA-256 is in `edge-155-final-evidence-20261013.zip.sha256`. The archive excludes the staged Edge workspace and its duplicated source/dependency tree.

It exited 1: UPS stayed at 59.7–60.0, but three WebGL frame-p95 measurements missed the unchanged 16.7 ms limit (26.20, 18.10, and 19.30 ms); the fourth was 12.50 ms. A second headed run used the same installed Edge executable and only the process-local `--force-high-performance-gpu` argument; it exited 0 on ANGLE NVIDIA GeForce RTX 4060 Laptop GPU (hardware). The test also observed textures ready, 5 rendered frames, and 5 simulation snapshots before loading the fixture, so its readiness wait was left unchanged. The Intel result remains a real default-adapter RED; the passing RTX run does not imply that Edge automatically selects the discrete adapter on every system. Chrome 137's segmented E5–33 evidence includes its native RTX 4060 E14 pass and vehicle, rail, rail-MP, management-MP, nuclear-MP, and map journeys.

A separate, headless Edge renderer probe confirms the local switch selects the intended adapter without changing OS preferences: Edge 155.0.4283.45 returned `ANGLE (NVIDIA, NVIDIA GeForce RTX 4060 Laptop GPU (0x000028A0) Direct3D11...)`, vendor NVIDIA, WebGL 2, and GL error 0.
